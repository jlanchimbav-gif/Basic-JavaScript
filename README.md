# JavaScript - Bases del Lenguaje

Proyecto para aprender y practicar los conceptos fundamentales de JavaScript.

## Contenido

- **Variables y Tipos de Datos**: `let`, `const`, `var`
- **Operadores**: Aritméticos, de comparación, lógicos
- **Estructuras de Control**: Condicionales (`if`, `switch`), Bucles (`for`, `while`)
- **Funciones**: Declaración, parámetros, retorno
- **Objetos y Arrays**: Manipulación de colecciones
- **DOM**: Interacción con el navegador
- **Promises y Async/Await**: Operaciones asincrónicas


## Cómo usar

1. Abre los archivos `.js` en tu editor
2. Lee los ejemplos y comentarios
3. Ejecuta el código en la consola o en Node.js
4. Experimenta modificando el código

## Ejecución

Para ejecutar un archivo:
```bash
node src/01-variables.js
```
